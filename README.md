# HandGlid

A professional desktop application that allows users to control their computer mouse using hand gestures captured through a webcam.

## Project Overview
HandGlid is designed to demonstrate Core Python, Python OOP, computer vision, algorithms, state management, error handling, modular architecture, and desktop automation.

## Features
- Real-time hand gesture tracking via webcam.
- Basic camera capture and configuration structure (Current state - STEP 1).

## Installation

### Prerequisites
- Python 3.x

### Setup Virtual Environment

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Linux/macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### Install Dependencies
```bash
pip install -r requirements.txt
```

## Usage
Run the minimal camera test:
```bash
python main.py
```
Press `q` or `ESC` to exit the webcam preview.
